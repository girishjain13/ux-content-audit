Runs on GitHub Actions — no server, no database
UX Lead · Content Strategist

Audits that render the real page.

A real headless browser loads the page, lets client-side JavaScript hydrate, scrolls to trigger lazy-loaded content, then scores it — not just missing title tags. Accessibility is severity-weighted, not a binary pass/fail. Journeys are path-aware, so a news story about a hospital wing "opening" doesn't get mistaken for a job listing.

Needs Actions: Read and write on this repo. Create one here — stored only in your browser, sent only to GitHub's own API.
Requires an ANTHROPIC_API_KEY repo secret (Settings → Secrets and variables → Actions) — never entered here, since Actions inputs aren't masked in run history the way secrets are. Unchecked or unset always falls back to the free rule-based classifier.
01

Render, don't fetch

Chromium executes the page — SPAs, hydration, and JS-injected content are visible to the audit, not just the initial server response. A short scroll cycle before extraction also triggers lazy-loaded images and cards that only mount on scroll.

02

Score like a lead

Accessibility is severity-weighted, not a binary "any issue = zero." SEO accounts for duplicate titles, not just missing ones. The "next sprint" recommendation ranks real accessibility and content issues above a handful of orphan pages.

03

Journeys with proof

Path-aware matching, not bag-of-words. A news story titled "new unit opening" won't get mistaken for a job listing, and an investor-relations page won't get credited as a customer journey stage just because a word overlaps.
